# Merge Conflict Arena

A progressive challenge repository for evaluating and improving development skills.


## How it works

Problems are organized by increasing difficulty. Each problem is self-contained and
describes the task to be solved.


## Workflow

For every problem:

1. **Create a new branch**
   - Use a clear naming convention:
     `problem-<number>`

2. **Implement the solution**
   - Follow the instructions in the problem description
   - Keep commits clean and meaningful

3. **Open a Pull Request**
   - Target: `main`
   - Include:
     - What you implemented
     - Any assumptions made
     - Notes or trade-offs (if relevant)


## Rules

- Do not modify other problems
- One problem per branch / PR
- Keep solutions minimal and focused
- Code should be readable and production-ready


## Goal

Demonstrate problem-solving, code quality, and Git workflow proficiency under
increasing complexity.
